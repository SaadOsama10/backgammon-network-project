🎲 Backgammon

A complete backgammon game in Java Swing (dice, hitting, the bar, bearing off, win detection). It runs here, in your browser, with CheerpJ (Java in WebAssembly): no install, no server.

This browser demo is local 2-player on one device. Browsers can't open raw TCP sockets, so the online mode (two machines through the game server) isn't available here. See local vs online play in the README for how to play online.

⏳ The first load downloads the Java runtime and can take a few seconds (up to a minute on a slow connection). Use a desktop browser; the game is mouse-only.

How to play

  1. Click Local 2-player (same device). White ⚪ starts; the bar above the board shows whose turn it is, and the board switches to that player after every turn, so just hand over the mouse.
  2. Click RD to roll the dice. Each die can be used once; doubles give four moves.
  3. Click one of your pieces, then the point to move to. White moves 24 → 1, Black moves 1 → 24. Landing on a lone enemy piece sends it to the bar.
  4. Pieces on the bar must re-enter first: click the W: / B: label, then the entry point. When all 15 pieces are home, select one and click BO to bear off.
  5. RE restarts, Out resigns. The first player to bear off all pieces wins.

About

  • Computer Network Concepts term project by Saed O S Radi (FSMVU, Spring 2026).
  • Online, the game is a TCP relay server plus two Swing clients. Here the same game logic runs twice in one page, connected by an in-memory transport that uses the same PLAYER / MOVE messages.
